# Website CV - Gita Fadila Mayangsari

CV online yang dibuat untuk tugas web. Berisi profil, pengalaman organisasi, pendidikan, keterampilan, proyek, dan form kontak.

**Demo:** https://gitafadila2605.github.io/cv-website/

## Fitur
- HTML semantik (header, nav, main, section, footer, tabel pendidikan)
- CSS responsif dengan Grid dan Flexbox, variabel CSS, mode terang dan gelap, serta tampilan cetak untuk simpan PDF
- JavaScript: ganti tema, menu mobile, filter pengalaman, menu aktif saat scroll, validasi form, salin email
- PHP: `contact.php` menyimpan pesan dari form ke `messages.txt` (butuh server PHP)

## Teknologi
HTML5, CSS3, JavaScript (ES6), PHP

## Cara menjalankan
- Cukup buka `index.html`, atau pakai ekstensi Live Server di VS Code.
- Untuk mencoba `contact.php`, taruh folder ini di `www` Laragon lalu buka lewat `http://localhost/cv-website/`.
- Di GitHub Pages, form otomatis beralih ke aplikasi email karena PHP tidak didukung.
